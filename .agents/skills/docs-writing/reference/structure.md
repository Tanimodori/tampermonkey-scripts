# 叙述整体结构

先判断主题属于两种骨架中的哪一种，再安排段落。

## 对象型骨架

1. 一句「是什么」。
2. 由什么构成的代码块，字段含义由 `/**/` 注释承载。
3. 次要内容。

## 特性或流程型骨架

1. 先把特性或流程整体讲清楚，必要时用代码辅助。
2. 再列次要注意事项。

## 章节安排

- 开头直接进入主题，不铺垫背景，重要内容前置。
- 章节顺序按整体到局部、逻辑先后或时间先后、重要到次要排列。以操作步骤为主的文档保持执行顺序。
- 每段描述放在最合适的章节，检查是否应该挪到别处。
- 同类文档保持同一结构。
- 章节不编号，标题具描述性。

## 对接已有结构

- 用户给出大纲时照写，新标题直接替换现有结构。
- 被点名权威模板时整体对齐其结构。
