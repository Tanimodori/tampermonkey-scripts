# 本地开发

## 前置

- Node.js 与 pnpm 由 Rush 管理。
- 外部服务未配置时，使用本地替代。

## 常用命令

```bash
rush install    # 安装依赖
rush build      # 构建全部项目
rushx lint      # 静态检查
rushx format    # 格式化
```

## 测试

```bash
rushx test        # 全部离线用例，无外部依赖
rushx test:live   # 真实上游，需要测试配置
```

## 本地状态

- 改动依赖包后要重新构建才会生效。
- 缓存目录可以整体删除，下次运行会重新生成。
