# 本地开发

## 前置

- Node.js 与 pnpm 由 Rush 管理。
- 外部服务未配置时，使用本地替代。

## 常用命令

```bash
rush update    # 安装依赖
rushx build    # 构建产物
rushx test     # 运行测试
rushx lint     # 静态检查
```

## 测试

```bash
rushx test        # 全部离线用例，无外部依赖
rushx test:live   # 真实上游，需要测试配置
```
