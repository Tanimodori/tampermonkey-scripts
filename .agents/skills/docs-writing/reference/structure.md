# 叙述整体结构

先判断主题属于哪一种骨架，再安排段落。

## 对象型骨架

1. 一句「是什么」。
2. 由什么构成的代码块，字段含义由 `/**/` 注释承载。
3. 次要内容。

范本：[对象与类型](../exemplars/class.md)。

## 总-分骨架

1. 一句说明整体是什么。
2. 按实际名称列出组成部分或维度，需要对比时用同一组维度列一张分工表。
3. 逐部分展开各自的规则与边界。
4. 必要时给核对方法或注意事项。

范本：[功能或切面](../exemplars/topic.md)。

## 清单型骨架

1. 一句通用约定。
2. 一览表。
3. 逐项展开：功能、参数、正常返回值。

范本：[端点表](../exemplars/endpoint.md)。

## 入口型骨架

1. 一句「是什么」。
2. 能力或内容索引。
3. 最小用法。

范本：[README](../exemplars/README.md)。

## 章节安排

- 开头直接进入主题，不铺垫背景，重要内容前置。
- 章节顺序按整体到局部、逻辑先后或时间先后、重要到次要排列。以操作步骤为主的文档保持执行顺序。
- 每段描述放在最合适的章节，检查是否应该挪到别处。
- 同类文档保持同一结构。
- 章节不编号，标题具描述性。

## 对接已有结构

- 用户给出大纲时照写，新标题直接替换现有结构。
- 被点名权威模板时整体对齐其结构。
